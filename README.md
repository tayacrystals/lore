# Lore

Zero-setup documentation static site generator.

## Quick Start

Run lore in your docs directory:

```bash
bunx @tayacrystals/lore
```

This builds your documentation to `./dist`. To start a dev server:

```bash
bunx @tayacrystals/lore dev
```

## Documentation

For full documentation, see the [docs](./docs/) directory or run `lore dev docs`.

## Features

- Zero setup
- Static site output
- MDX with custom components
- Plugin system with 9 built-in plugins
- Versioning
- Internationalization
- Full-text search
- Collections from JSON data
- Dark and light mode
- Syntax highlighting via Expressive Code
- Dead link checking at build time
